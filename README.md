# Ahmed Life Lab

Personal life and learning website for Ahmed.

## Website
https://ahmed-life-lab-benji14.vercel.app

## Files
- `index.html`: website including university planning, writing, Life Organizer, sports, car planner, coding, projects and daily dashboard
- `ahmed-icon.svg` and `apple-touch-icon.png`: app branding
- `manifest.webmanifest`: home screen metadata

## Hosting
Existing Vercel project: `ahmed-life-lab` under the Benji team.

## Important
This repository contains the website source only. User notes, books and appointments are stored separately in each device's browser at present. There is no Supabase connection or automatic cross-device sync.

Before enabling cloud storage or real user accounts, configure authorization and appropriate private data access policies.

This repository is presently public. Never commit keys, passwords, healthcare information, personal journals or private records.
